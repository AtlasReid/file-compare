# File comparison

Compare two files byte for byte, verify a file against a SHA-256 checksum, or compare two checksums. The two-file view visualizes the SHA-256 pipeline and highlights differing digest bits. Files and comparison results are processed locally in the browser.

The site is plain HTML, CSS, and JavaScript. Serve the repository root over HTTP for local testing. GitHub Pages serves the root of the main branch.

Third-party notices accompany the vendored Three.js code and the split-flap and dot-matrix display implementations.
